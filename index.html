Pengertian Kabel LAN

Kabel LAN (UTP) adalah kabel berisi 8 helai kabel kecil yang terbagi menjadi 4 pasang berpilin. Kabel ini menghubungkan perangkat dalam satu jaringan lokal (Local Area Network) lewat konektor RJ-45.

Kabel Straight

Susunan warna di kedua ujung kabel sama persis (T568B – T568B). Dipakai untuk menghubungkan perangkat yang berbeda jenis, misalnya komputer ke switch/hub atau komputer ke router.

Kabel Cross-over

Susunan warna di kedua ujung berbeda (T568B – T568A), sehingga jalur kirim dan terima bersilang. Dipakai untuk menghubungkan perangkat yang sejenis, misalnya komputer ke komputer secara langsung.

Alat dan Bahan

Alat

  • Crimping tool (tang crimping RJ-45)
  • Cutter atau pengupas kabel (stripper)
  • LAN tester
  • Gunting / pemotong kabel

Bahan

  • Kabel UTP Cat5e / Cat6 secukupnya
  • Konektor RJ-45
  • Boot konektor (opsional)

Cara Merangkai Kabel LAN

Langkah sama untuk kedua tipe. Bedanya hanya pada urutan warna di ujung kedua.

  1. Potong kabel UTP sesuai kebutuhan, lalu kupas selubung luar sekitar 2–3 cm tanpa melukai kabel kecil di dalamnya.
  2. Urai 4 pasang kabel, luruskan, lalu susun sesuai urutan warna. Straight: T568B di kedua ujung. Cross-over: T568B di ujung pertama, T568A di ujung kedua.
  3. Rapikan dan potong rata ujung kabel, sisakan sekitar 1,2 cm dari selubung.
  4. Masukkan kabel ke konektor RJ-45 (klip menghadap ke bawah) sampai semua ujung kabel menyentuh bagian depan konektor.
  5. Jepit konektor dengan crimping tool sampai terdengar bunyi klik.
  6. Ulangi di ujung lainnya, lalu uji dengan LAN tester. Lampu 1 sampai 8 harus menyala berurutan (straight) atau 1↔3 dan 2↔6 bersilang (cross-over).

Sharing Data dengan Kabel LAN

Alat untuk sharing data

  • 2 komputer/laptop dengan port LAN (Ethernet)
  • 1 kabel LAN cross-over (atau straight bila NIC mendukung Auto MDI-X)
  • Sistem operasi dengan fitur file sharing (misal Windows)

Konsep Peer to Peer

Dua komputer terhubung langsung dan saling berbagi file tanpa server. Setiap komputer bisa menjadi pengirim sekaligus penerima.

Cara sharing data

  1. Hubungkan kedua komputer dengan kabel LAN ke port Ethernet masing-masing.
  2. Atur IP address manual: Control Panel → Network and Sharing Center → Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4).
  3. PC 1: IP 192.168.1.1, Subnet mask 255.255.255.0. PC 2: IP 192.168.1.2, Subnet mask 255.255.255.0.
  4. Buka Advanced sharing settings, aktifkan Network discovery dan File and printer sharing.
  5. Klik kanan folder yang ingin dibagikan → Properties → tab Sharing → Share, pilih pengguna dan izin akses (Read atau Read/Write).
  6. Uji koneksi: buka Command Prompt lalu ketik ping 192.168.1.2 dari PC 1. Balasan "Reply from..." menandakan terhubung.
  7. Dari PC 2, buka File Explorer dan ketik \\192.168.1.1 di address bar untuk mengakses folder yang dibagikan.
